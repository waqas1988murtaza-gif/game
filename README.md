# 🎮 EduPlay Sindh — Bachon Ka Quiz Game

Pre-Nursery se Class 5 tak bachon ke liye muft quiz game — Zara mascot (Urdu awaz) ke saath.

**Live:** https://waqas1988murtaza-gif.github.io/game/

## Kya hai
- 184 sawalat (Math, English, Urdu, Science, Computer, Islamiat, General Knowledge, Colors, Shapes, Numbers, Alphabets)
- Har subject me best-score tracking (localStorage)
- Zara mascot Urdu TTS ke saath sawal parhti hai
- Offline-safe: fonts self-hosted, koi external dependency nahi
- Mobile-friendly + installable (PWA manifest)

## Chalana
Koi build step nahi — `index.html` ko browser me kholo, ya GitHub Pages se serve karo.
